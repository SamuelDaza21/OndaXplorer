## 📚 Sobre el proyecto

Plataforma web que explora conceptos de física de forma interactiva y visual: **ondas, cinemática, energía, óptica y más**. Pensada para el aprendizaje autónomo, combina teoría, laboratorios virtuales y ejercicios prácticos.

---

## ✨ Características

- 📚 **Temas de física**: ondas, cinemática, energía, leyes de Newton, óptica y sistemas de unidades
- 🧪 **Laboratorios interactivos**: simulaciones prácticas por tema
- 📝 **Ejercicios**: práctica y evaluación de los conceptos vistos
- 🎬 **Multimedia**: material audiovisual de apoyo al aprendizaje
