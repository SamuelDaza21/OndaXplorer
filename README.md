# 🌊 OndaXplorer

Plataforma educativa interactiva de física para la exploración de conceptos de ondas, cinemática, energía, óptica y más.

## ✨ Contenido

- **Temas de física**: Ondas, Cinemática, Energía, Leyes de Newton, Óptica (espejos) y Sistemas de Unidades.
- **Laboratorios interactivos**: Simulaciones prácticas por tema.
- **Ejercicios**: Práctica y evaluación de los conceptos vistos.
- **Multimedia**: Material audiovisual de apoyo al aprendizaje.
